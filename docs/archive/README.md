# Archived docs

The files in this folder are historical, point-in-time documents from an
earlier stage of this project. They describe:

- An earlier client-specific deployment ("Al Hussam Tailor ERP" /
  "Al-Mamlaka Tailor ERP" branding) that predates the current multi-tenant
  "Tafsell" product.
- A superseded infrastructure split — frontend on Vercel, backend + Postgres
  on Coolify/Hetzner — including a reference to a `HETZNER_DEPLOYMENT.md`
  file that no longer exists in this repo. The current production target is
  a single Railway service; see [`../../DEPLOYMENT.md`](../../DEPLOYMENT.md).
- Security/hardening and handover audits performed against that earlier
  single-tenant state.

They are kept for historical reference only and are not maintained. For
current, accurate information, see [`../../README.md`](../../README.md) and
[`../../DEPLOYMENT.md`](../../DEPLOYMENT.md).
